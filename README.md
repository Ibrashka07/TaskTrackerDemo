# Task Tracker Demo (Qt)

Сквозной проект: **Трекер задач**. 
Этап 1: Демонстрация дерева объектов QObject и управления памятью в Qt (на основе Лабораторной работы №2).

## Описание этапа

На данном этапе реализовано GUI-приложение, которое демонстрирует механизм владения объектами в Qt. 
Программа показывает:
- Автоматическое удаление дочерних виджетов при удалении родителя.
- Поведение метода `setParent()` при смене владельца.
- Разницу между `setParent(nullptr)` и удалением через `deleteLater()`.
- Работу умного указателя `QPointer` для защиты от висячих указателей.

## Функционал (демо)

Окно содержит виджеты, стилизованные под интерфейс трекера задач:
- Поле ввода (для будущего добавления задач).
- Панель задач (в которой находятся "Задача 1" и "Задача 2").
- Кнопки-демонстрации управления памятью:
  1. **Переместить Задачу 2** — смена родителя (`setParent`) между панелью и главным окном.
  2. **Удалить панель задач** — демонстрация автоматического удаления детей (`deleteLater`).
  3. **Демо setParent(nullptr)** — отвязка объекта, приводящая к необходимости удалять его вручную.
